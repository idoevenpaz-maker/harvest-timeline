# טרור יהודי

ציר זמן של אירועי אלימות מתנחלים נגד פלסטינים בגדה המערבית, יום אחר יום, עם כתבות וסרטונים לכל אירוע.

- **נתוני האירועים:** יש דין, מתוך `https://settlers-violence-opt.site/data.json` (הדשבורד שמוטמע ב-yesh-din.org).
- **כתבות וסרטונים:** Google Sheet בשם "טרור יהודי – כתבות וסרטונים". כל שורה מייצגת קישור אחד, ולכל אירוע אפשר להוסיף כמה קישורים.

## הוספת כתבה או סרטון

1. באתר, ליד שם היישוב בכל אירוע מופיע המזהה שלו (למשל `h123` או `o717`).
2. בגיליון ממלאים שורה: **מזהה**, **סוג** (`כתבה` או `סרטון`), **כותרת**, **קישור** (כתובת מלאה שמתחילה ב-https), **מקור** (לא חובה).
3. הקישור יופיע באתר בעדכון האוטומטי הבא (פעמיים ביום). לעדכון מיידי: GitHub ← Actions ← Sync data ← Run workflow.

אם אחד המזהים לא קיים או שהקישור שגוי, השורה מדולגת ומופיעה אזהרה בריצה של ה-Action.

## עדכון אוטומטי

`.github/workflows/sync.yml` מריץ את `scripts/sync.mjs` פעמיים ביום. הסקריפט מוריד את הנתונים ואת הגיליון, כותב לקבצים `data/incidents.json` ו-`data/media.json` ושומר commit אם משהו השתנה.

## הרצה מקומית

```
node scripts/sync.mjs
node scripts/serve.mjs 5185
```
